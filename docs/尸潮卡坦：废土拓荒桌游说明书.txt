《尸潮卡坦：废土拓荒》规则 v2.0
1. 游戏概述
《尸潮卡坦：废土拓荒》是一款丧尸末日主题的资源建设类桌游。玩家扮演废土幸存者营地的领袖，通过获取资源、建立营地、升级堡垒、修建运输线、派出装甲车队探索迷雾区域，并征召民兵抵御尸潮。
游戏的核心目标是：
第一个达到12点胜利点的玩家获胜。
________________________________________
2. 游戏人数与时间
项目	内容
玩家人数	2—6人
推荐时间	60—90分钟
推荐年龄	10岁以上
获胜条件	率先达到12点胜利点

4. 地块说明
4.1 农场
农场产出：
食物
当骰子点数等于农场上的数字标记时，拥有相邻营地或堡垒的玩家获得食物。
________________________________________
4.2 林地
林地产出：
木材
当骰子点数等于林地上的数字标记时，拥有相邻营地或堡垒的玩家获得木材。
________________________________________
4.3 废弃工厂
废弃工厂产出：
金属
当骰子点数等于废弃工厂上的数字标记时，拥有相邻营地或堡垒的玩家获得金属。
________________________________________
4.4 废墟城区
废墟城区产出：
燃料
当骰子点数等于废墟城区上的数字标记时，拥有相邻营地或堡垒的玩家获得燃料。
________________________________________
4.5 军事营地
军事营地产出：
弹药
当骰子点数等于军事营地上的数字标记时，拥有相邻营地或堡垒的玩家获得弹药。
________________________________________
4.6 感染区
感染区不产资源。
感染区的作用是：
1.	尸潮标记的初始位置。
2.	商人标记的初始位置。
3.	探索迷雾时，如果翻出感染区，尸潮进度条前进1格。
感染区不放置数字标记。
________________________________________
4.7 普通地块 / 空地
普通地块对应原版卡坦岛中的海洋地块。
普通地块的规则：
1.	不产资源。
2.	不放置数字标记。
3.	没有特殊效果。
4.	可以作为地图阻隔区域。
5.	玩家可以通过装甲车队沿普通地块边缘继续探索。
普通地块可以理解为：
废土荒野、废弃道路、无人区、隔离带。
________________________________________
4.8 废弃仓库
废弃仓库对应原版卡坦岛扩展中的金矿地块。
废弃仓库产出：
任意资源
当骰子点数等于废弃仓库上的数字标记时，相邻玩家可以自由选择获得哪种资源。
相邻建筑	获得资源
营地	任意1张资源
堡垒	任意2张资源
堡垒获得的2张资源可以相同，也可以不同。
例如：
玩家A的堡垒相邻废弃仓库。
本回合骰子点数触发废弃仓库。
玩家A可以选择：
•	2张金属；
•	或1张食物 + 1张弹药；
•	或1张木材 + 1张燃料。

7行地图之外的所有区域，均视为：
不可探索迷雾区域
不可探索迷雾区域规则如下：
1.	不放置任何地块。
2.	不放置数字标记。
3.	不产出资源。
4.	玩家不能在其中建立营地、堡垒、运输线或装甲车队。
5.	装甲车队不能进入地图外侧的不可探索迷雾区域。
6.	尸潮不能移动到不可探索迷雾区域。
7.	商人不能移动到不可探索迷雾区域。
8.	不可探索迷雾区域只作为地图边界存在。

5.5 资源聚集区规则
地图中的资源地块不能平均散布，而应组成若干个资源聚集区。
资源聚集区分为三种：
类型	规模	说明
大型资源聚集区	12—20个资源地块	主要发展区域，不放废弃仓库
中型资源聚集区	6—10个资源地块	次级发展区域，通常不放废弃仓库
小型资源聚集区	2—5个资源地块	探索与争夺区域，可以放废弃仓库
________________________________________
5.6 空地隔离规则
不同资源聚集区之间必须用普通地块 / 空地隔开。
规则如下：
1.	两个不同资源聚集区不能直接相邻。
2.	不同资源聚集区之间至少要有1格普通地块 / 空地。
3.	普通地块 / 空地不产资源，不放数字。
4.	玩家需要通过运输线或装甲车队连接不同资源聚集区。
5.	空地越多，地图的探索感和路线规划感越强。
________________________________________
5.7 废弃仓库放置规则
废弃仓库是强力资源地块，放置时必须遵守以下规则：
1.	废弃仓库只能放在小型资源聚集区中。
2.	大型资源聚集区中不能出现废弃仓库。
3.	中型资源聚集区中原则上不放废弃仓库。
4.	每个小型资源聚集区最多放置1个废弃仓库。
5.	废弃仓库不能与另一个废弃仓库相邻。
6.	废弃仓库周围应至少有1—2个普通资源地块，使其成为值得争夺的小资源点。
________________________________________
5.8 感染区放置规则
感染区用于放置尸潮，并制造地图压力。
感染区放置规则如下：
1.	标准地图放置4个感染区。
2.	感染区不产资源，不放数字。
3.	感染区可以放在空地隔离带中。
4.	感染区可以靠近资源聚集区边缘。
5.	感染区不能放在大型资源聚集区正中心。
6.	任意两个感染区之间至少间隔2格。
7.	感染区不能与废弃仓库相邻。
推荐放置方式：
感染区位置	作用
中央偏上	制造中心压力
中央偏下	阻隔路线
左侧边缘	限制左侧扩张
右侧边缘	限制右侧扩张
________________________________________
5.9 推荐地图结构
玩家可以从以下几种地图结构中选择一种作为本局剧本。
________________________________________
结构一：中央大型资源区 + 周围小资源区
地图中央有一个大型资源聚集区，周围有若干小型资源聚集区。
特点：
1.	中央区域资源丰富。
2.	玩家前期容易产生竞争。
3.	周围小资源区提供废弃仓库。
4.	小资源区之间由空地隔开。
5.	适合作为标准地图。
结构示意：
O O O 小区 O O 小区 O O
O O O O O O O O O O
O O 大型资源聚集区 O O
O O 大型资源聚集区 O O O
O O 大型资源聚集区 O O
小区 O O O O O O 小区
O O O 小区 O O O O O
________________________________________
结构二：左侧大型资源区 + 右侧多个小资源区
左侧是一大片稳定资源区，右侧分布多个小型资源聚集区。
特点：
1.	左侧适合稳定发展。
2.	右侧适合争夺废弃仓库。
3.	玩家会在左右两侧形成不同策略。
4.	适合做“主城安全区 + 废土探索区”的地图。
________________________________________
结构三：右侧大型资源区 + 左侧多个小资源区
右侧是主要资源区，左侧分布多个小型资源聚集区。
特点：
1.	右侧资源丰富，容易形成主战场。
2.	左侧小资源区更适合装甲车队扩张。
3.	废弃仓库集中在左侧小资源区。
4.	商人牌价值较高。
________________________________________
结构四：左右各一个较大资源区 + 中间多个小资源区
左右两侧各有一个较大的资源聚集区，中间分布若干小型资源区。
特点：
1.	左右玩家发展相对平衡。
2.	中间小资源区成为争夺点。
3.	废弃仓库主要位于中间。
4.	适合4人局。
________________________________________
结构五：全小型资源聚集区
整张地图由多个小型资源聚集区组成，没有大型资源区。
特点：
1.	空地非常多。
2.	玩家必须不断扩张连接不同资源区。
3.	交易更加重要。
4.	装甲车队价值更高。
5.	适合进阶玩法。
________________________________________
5.10 标准地图摆放流程
地图摆放按照以下步骤进行：
第一步：摆出72格地图框架
按照以下行数摆放空白六边形地块位置：
9 — 10 — 11 — 12 — 11 — 10 — 9
________________________________________
第二步：先放置普通地块 / 空地
先将34个普通地块 / 空地放入地图中，用于形成隔离带。
空地应优先放在：
1.	不同资源聚集区之间；
2.	地图中央通道；
3.	地图边缘区域；
4.	感染区周围；
5.	小型资源聚集区外围。
________________________________________
第三步：放置大型或中型资源聚集区
根据本局选择的地图结构，放置大型或中型资源聚集区。
大型资源聚集区中只能使用以下地块：
1.	农场；
2.	林地；
3.	废弃工厂；
4.	废墟城区；
5.	军事营地。
大型资源聚集区中不能放置：
1.	废弃仓库；
2.	感染区。
________________________________________
第四步：放置小型资源聚集区
在地图边缘或空地隔离带外侧放置小型资源聚集区。
小型资源聚集区由2—5个资源地块组成。
每个小型资源聚集区可以包含：
1.	普通资源地块；
2.	最多1个废弃仓库。
小型资源聚集区示例：
H F
W
A H
G M
F W
H
________________________________________
第五步：放置感染区
放置4个感染区。
感染区建议放在：
1.	空地隔离带中；
2.	大型资源区边缘；
3.	小型资源区附近但不相邻废弃仓库；
4.	地图中部偏外的位置。
________________________________________
第六步：检查地图合法性
完成摆放后，检查以下条件：
1.	全图是否为72格。
2.	是否符合9—10—11—12—11—10—9的行数。
3.	废弃仓库是否只出现在小型资源聚集区。
4.	大型资源聚集区是否没有废弃仓库。
5.	不同资源聚集区之间是否有空地隔开。
6.	感染区是否没有与废弃仓库相邻。
7.	普通地块 / 空地是否不放数字。
8.	地图外侧是否没有可探索地块。
________________________________________
5.11 初始尸潮与商人放置
游戏开始时：
1.	尸潮标记放在任意一个感染区上。
2.	商人标记放在任意一个感染区上。
3.	尸潮和商人可以放在同一个感染区，也可以放在不同感染区。
4.	如果地图中有中央感染区，建议尸潮初始放在中央感染区。
5.	商人初始不属于任何玩家。
________________________________________
5.12 初始营地放置规则
玩家开局放置营地时，必须遵守以下规则：
1.	初始营地只能放在大型资源聚集区或中型资源聚集区周围。
2.	初始营地不能直接放在废弃仓库相邻的交叉点上。
3.	初始营地不能放在只接触普通地块 / 空地的位置。
4.	初始营地不能放在只接触感染区的位置。
5.	初始营地必须至少相邻1个产资源地块。
6.	初始营地必须遵守距离规则。
7.	任意两个营地或堡垒之间至少间隔一个空交叉点。
________________________________________
5.13 初始路线放置规则
每名玩家放置初始营地后，必须在该营地旁放置1条运输线。
开局时：
1.	只能放置运输线。
2.	不能放置装甲车队。
3.	运输线必须连接自己的初始营地。
4.	运输线不能伸向地图外侧不可探索迷雾区域。
________________________________________
5.14 初始资源获得
所有玩家放置完第二个初始营地后，从第二个营地相邻的产资源地块获得初始资源。
规则如下：
相邻地块	获得资源
农场	食物 ×1
林地	木材 ×1
废弃工厂	金属 ×1
废墟城区	燃料 ×1
军事营地	弹药 ×1
废弃仓库	任意资源 ×1
感染区	不获得资源
普通地块 / 空地	不获得资源
如果第二个营地相邻多个产资源地块，则分别获得对应资源。
________________________________________

6.4 废弃仓库数字限制
废弃仓库可以放置数字标记，但必须遵守以下限制：
1.	废弃仓库不能放置数字6。
2.	废弃仓库不能放置数字8。
3.	废弃仓库不能与另一个废弃仓库相邻。
4.	每个小型资源聚集区最多只能有1个废弃仓库。
5.	废弃仓库所在的小型资源聚集区，最多只能有1个高概率数字。
推荐废弃仓库使用以下数字：
3、4、10、11
如果废弃仓库数量超过4个，可以额外使用：
2、12、5、9
但仍然不能使用6或8。
________________________________________
6.5 高概率数字限制
高概率数字指：
6 和 8
数字6和8放置时必须遵守以下规则：
1.	数字6不能与数字6相邻。
2.	数字8不能与数字8相邻。
3.	数字6不能与数字8相邻。
4.	同一个小型资源聚集区内最多只能出现一个6或8。
5.	废弃仓库不能放置6或8。
6.	感染区、普通地块、空地不放置任何数字。
________________________________________
6.6 大型资源聚集区数字规则
大型资源聚集区是主要资源区，可以拥有多个高概率数字。
放置规则如下：
1.	大型资源聚集区可以放置多个6和8。
2.	任意两个6或8不能相邻。
3.	同一种资源不能集中获得所有高概率数字。
4.	大型资源聚集区中，6和8应尽量分散在不同方向。
5.	如果大型资源区靠近感染区，靠近感染区的资源地块可以放置较高数字，以增加争夺风险。
推荐分布：
资源区规模	推荐6/8数量
12—14个资源地块	2个
15—17个资源地块	3个
18—20个资源地块	4个
________________________________________
6.7 中型资源聚集区数字规则
中型资源聚集区可以放置1—2个高概率数字。
规则如下：
1.	中型资源区最多放置2个6或8。
2.	如果有2个6或8，它们不能相邻。
3.	中型资源区不建议放置废弃仓库。
4.	中型资源区的数字应包含高、中、低概率数字。
________________________________________
6.8 小型资源聚集区数字规则
小型资源聚集区是特殊争夺区，数字不能过强。
规则如下：
1.	每个小型资源聚集区最多放置1个高概率数字。
2.	如果小型资源区中有废弃仓库，则废弃仓库不能放6或8。
3.	小型资源区中的废弃仓库推荐放置3、4、10、11。
4.	小型资源区不应同时拥有废弃仓库和多个高概率资源地块。
5.	如果小型资源区只有2个资源地块，则不建议放置6或8。
________________________________________
6.9 数字标记放置流程
数字标记按照以下步骤放置。
________________________________________
第一步：先给废弃仓库放数字
先从以下数字中选择数字给废弃仓库：
3、4、10、11
如果有4个废弃仓库，则分别使用：
3、4、10、11
放置时可以随机，也可以由玩家共同决定。
废弃仓库不能放置：
6、8
________________________________________
第二步：移除已使用数字
将已经放在废弃仓库上的数字，从标准数字池中移除。
例如：
如果4个废弃仓库分别放置了：
3、4、10、11
则从标准数字池中移除：
3、4、10、11
剩余数字用于其他资源地块。
________________________________________
第三步：给大型资源聚集区放数字
将剩余数字中的高概率数字优先分配给大型资源聚集区。
放置时遵守：
1.	6和8不能相邻。
2.	6和8不能集中在同一种资源上。
3.	6和8不能全部放在同一个方向。
4.	大型资源区内部应同时存在高、中、低概率数字。
________________________________________
第四步：给中型资源聚集区放数字
中型资源区使用剩余数字。
放置时遵守：
1.	每个中型资源区最多2个高概率数字。
2.	6和8不能相邻。
3.	数字分布应尽量均衡。
4.	不要让某一种资源在中型区全部拥有高数字。
________________________________________
第五步：给小型资源聚集区放数字
最后给小型资源区剩余资源地块放数字。
放置时遵守：
1.	每个小型资源区最多1个高概率数字。
2.	有废弃仓库的小型资源区不建议再放6或8。
3.	小型资源区可以更多使用3、4、10、11、2、12等数字。
4.	小型资源区的数字不能过于集中，否则会导致废弃仓库过强。
________________________________________
第六步：最终检查
数字放置完成后，检查以下条件：
1.	是否所有产资源地块都有数字。
2.	感染区是否没有数字。
3.	普通地块 / 空地是否没有数字。
4.	地图外侧不可探索迷雾区域是否没有数字。
5.	废弃仓库是否没有放6或8。
6.	任意6和8是否都没有相邻。
7.	小型资源聚集区是否最多只有1个高概率数字。
8.	同一种资源是否没有过度集中高概率数字。
________________________________________
6.10 随机数字放置规则
如果玩家希望更接近原版卡坦岛的随机体验，可以使用随机数字放置法。
随机放置流程如下：
1.	将所有数字标记洗混。
2.	先抽取合法数字放到废弃仓库上。
3.	废弃仓库不能放6或8。
4.	再将剩余数字随机放到其他产资源地块上。
5.	如果出现6和8相邻，必须交换数字。
6.	如果小型资源区出现多个6或8，必须交换数字。
7.	如果同一种资源获得过多高概率数字，建议重新调整。
________________________________________
6.11 固定数字放置规则
如果玩家希望地图更平衡，可以使用固定数字放置法。
固定放置原则如下：
1.	大型资源区优先放置6、8、5、9。
2.	中型资源区使用5、9、4、10、3、11。
3.	小型资源区使用3、4、10、11、2、12。
4.	废弃仓库优先使用3、4、10、11。
5.	感染区附近可以放置较高数字，增加风险收益。
6.	靠近地图边缘的小资源区不宜放置过多高数字。
________________________________________
6.12 数字概率参考
数字出现概率如下：
数字	概率强度
6、8	最高
5、9	较高
4、10	中等
3、11	较低
2、12	最低
数字放置时应避免：
1.	6和8相邻；
2.	废弃仓库拿到6或8；
3.	一个小型资源区同时拥有多个高概率数字；
4.	某一种资源集中拥有过多6和8；
5.	所有高数字都集中在同一名玩家容易占据的位置。
________________________________________
6.13 非标准地块数量下的数字规则
如果玩家自定义地图，不使用标准34个产资源地块，则按以下方式调整数字池。
产资源地块少于34个
从标准数字池中移除部分数字。
优先移除：
2、12、3、11
不要优先移除6和8，否则地图资源产出会变慢。
________________________________________
产资源地块多于34个
在标准数字池基础上额外加入数字。
推荐按以下顺序增加：
3、11、4、10、5、9、2、12
只有在资源地块非常多时，才额外增加6或8。
________________________________________
6.14 数字放置完成后的游戏开始条件
只有当以下条件全部满足时，游戏才可以开始：
1.	地图共有72个可玩地块。
2.	地图外侧区域为不可探索迷雾区域。
3.	所有产资源地块均已放置数字。
4.	所有普通地块 / 空地没有数字。
5.	所有感染区没有数字。
6.	废弃仓库只出现在小型资源聚集区。
7.	废弃仓库没有放置6或8。
8.	6和8没有相邻。
9.	所有玩家完成初始营地和运输线放置。
10.	尸潮和商人已经放在感染区上。

游戏开始时：
尸潮进度条为0。
当尸潮进度条达到6格时，触发尸潮围城。

9. 玩家初始设置
9.1 玩家获得棋子
每名玩家选择一种颜色，并获得：
棋子	数量
营地	5个
堡垒	4个
运输线	15条
装甲车队	10个
民兵	12个
哨塔	4个
________________________________________
9.2 初始营地与运输线放置
每名玩家按照顺序放置初始建筑。
第一轮放置：
1.	玩家按照顺时针顺序，每人放置1个营地。
2.	每个玩家在该营地旁连接1条运输线。
第二轮放置：
1.	按照反向顺序，每人再放置1个营地。
2.	每个玩家在该营地旁连接1条运输线。
________________________________________
9.3 初始营地放置限制
初始营地必须遵守以下规则：
1.	只能放在中心公开区。
2.	不能放在接触迷雾地块的交叉点上。
3.	必须遵守距离规则。
4.	不能与任何已有营地或堡垒相邻。
5.	两个营地之间至少间隔一个空交叉点。
________________________________________
9.4 初始资源获得
所有玩家放置完第二个营地后，从第二个营地相邻的公开地块获得初始资源。
规则：
1.	第二个营地相邻农场，获得1食物。
2.	第二个营地相邻林地，获得1木材。
3.	第二个营地相邻废弃工厂，获得1金属。
4.	第二个营地相邻废墟城区，获得1燃料。
5.	第二个营地相邻军事营地，获得1弹药。
6.	第二个营地相邻废弃仓库，获得任意1张资源。
7.	第二个营地相邻感染区，不获得资源。
8.	第二个营地相邻普通地块 / 空地，不获得资源。

10. 建造价格表
10.1 运输线
运输线用于陆地扩张。
建筑	费用
运输线	木材 ×1 + 金属 ×1
运输线必须连接：
1.	自己已有的营地；
2.	自己已有的堡垒；
3.	自己已有的运输线；
4.	自己已有的装甲车队。
________________________________________
10.2 装甲车队
装甲车队用于探索迷雾区域。
建筑	费用
装甲车队	弹药 ×1 + 燃料 ×1
装甲车队必须连接：
1.	自己已有的营地；
2.	自己已有的堡垒；
3.	自己已有的运输线；
4.	自己已有的装甲车队。
装甲车队可以连接迷雾地块边缘，并触发探索。
________________________________________
10.3 营地
营地是基础建筑。
建筑	费用
营地	食物 ×1 + 木材 ×1 + 燃料 ×1 + 弹药 ×1
营地效果：
1.	价值1点胜利点。
2.	相邻地块产出时获得1张资源。
3.	每个营地最多驻守2个民兵。
4.	可以建造1座哨塔。
________________________________________
10.4 堡垒
堡垒由营地升级而来。
建筑	费用
堡垒	食物 ×2 + 金属 ×3
堡垒效果：
1.	价值2点胜利点。
2.	相邻地块产出时获得2张资源。
3.	每个堡垒最多驻守2个民兵。
4.	可以建造1座哨塔。
5.	堡垒本身不提供防御值。
________________________________________
10.5 哨塔
哨塔是手牌上限建筑。
建筑	费用
哨塔	金属 ×1 + 木材 ×1
哨塔效果：
1.	哨塔不提供防御值。
2.	每有1座哨塔，玩家手牌上限增加2张。
3.	每个营地或堡垒旁最多建造1座哨塔。
4.	如果堡垒被尸潮围城降级，且该堡垒旁有哨塔，哨塔一同被摧毁。
________________________________________
10.6 民兵
民兵是防御尸潮的核心单位。
单位	费用
征召民兵	金属 ×1 + 弹药 ×1
征召规则：
1.	民兵必须放在自己的营地或堡垒上。
2.	每个营地或堡垒最多驻守2个民兵。
3.	新征召的民兵为未激活状态。
________________________________________
10.7 激活民兵
行动	费用
激活1个民兵	食物 ×1
激活规则：
1.	未激活民兵可以通过支付食物变为激活状态。
2.	本回合刚激活的民兵不能立刻使用。
3.	本回合刚激活的民兵从玩家下一个回合开始才可以使用。
4.	已激活民兵可以参与尸潮围城防御。
5.	已激活民兵可以驱逐尸潮。
6.	已激活民兵可以移动到相连的营地或堡垒。
________________________________________
10.8 发展卡
卡牌	费用
发展卡	食物 ×1 + 金属 ×1 + 弹药 ×1
发展卡购买后：
1.	从发展卡牌堆顶抽1张。
2.	保密放入手牌。
3.	本回合新购买的发展卡不能立刻使用。
4.	每回合最多使用1张发展卡。
5.	秘密据点卡不需要主动使用，达到胜利条件时公开即可。
________________________________________
11. 回合流程
每名玩家的回合按照以下顺序进行：
1.	准备阶段
2.	掷骰阶段
3.	尸潮阶段
4.	交易阶段
5.	建造阶段
6.	民兵阶段
7.	发展卡阶段
8.	检查胜利
________________________________________
12. 准备阶段
在玩家回合开始时，处理自己的民兵状态。
如果玩家上一个回合激活了民兵，并且这些民兵尚未可以使用，则从本回合开始，这些民兵正式成为可使用的已激活民兵。
________________________________________
13. 掷骰阶段
当前玩家掷两颗六面骰。
如果掷出的点数不是7，则所有对应数字地块产出资源。
如果掷出的点数是7，则不产资源，进入尸潮阶段。
________________________________________
14. 资源产出规则
14.1 普通资源地块产出
当骰子点数等于某个地块上的数字标记时，该地块产出资源。
相邻建筑	获得资源
营地	1张
堡垒	2张
例如：
骰子点数为8。
地图上数字8的农场产出食物。
玩家A有1个营地相邻，获得1食物。
玩家B有1个堡垒相邻，获得2食物。
________________________________________
14.2 废弃仓库产出
废弃仓库被触发时，玩家获得任意资源。
相邻建筑	获得资源
营地	任意1张
堡垒	任意2张
________________________________________
14.3 尸潮封锁
如果尸潮标记在某个地块上，该地块不产资源。
即使骰子点数等于该地块数字，也不会产出资源。
尸潮可以封锁：
1.	农场；
2.	林地；
3.	废弃工厂；
4.	废墟城区；
5.	军事营地；
6.	废弃仓库。
________________________________________
15. 掷出7的规则
当玩家掷出7时，按照以下顺序处理：
1.	检查所有玩家手牌数量。
2.	超过手牌上限的玩家弃掉一半资源。
3.	当前玩家移动尸潮标记。
4.	当前玩家从尸潮所在地块相邻的一名玩家手中随机抽1张资源。
5.	尸潮进度条前进1格。
6.	如果尸潮进度条达到6格，结算尸潮围城。
________________________________________
16. 手牌上限与弃牌
16.1 基础手牌上限
每名玩家的基础手牌上限为：
7张
当骰子掷出7时，手牌数量超过上限的玩家必须弃牌。
________________________________________
16.2 哨塔增加手牌上限
每有1座哨塔，玩家手牌上限增加2张。
哨塔数量	手牌上限
0座	7张
1座	9张
2座	11张
3座	13张
________________________________________
16.3 弃牌规则
当掷出7时：
1.	只有超过自己手牌上限的玩家需要弃牌。
2.	弃牌数量为当前手牌数量的一半。
3.	弃牌数量向下取整。
例如：
玩家A没有哨塔，手牌上限为7。
玩家A有9张资源卡。
掷出7后，玩家A需要弃掉4张资源卡。
玩家B有1座哨塔，手牌上限为9。
玩家B有9张资源卡。
掷出7后，玩家B不需要弃牌。
玩家C有1座哨塔，手牌上限为9。
玩家C有10张资源卡。
掷出7后，玩家C需要弃掉5张资源卡。
________________________________________
17. 尸潮标记规则
17.1 尸潮移动
当掷出7时，当前玩家必须移动尸潮标记。
尸潮可以移动到任意已经翻开的地块上。
尸潮不能移动到未翻开的迷雾地块上。
________________________________________
17.2 尸潮封锁
尸潮所在的地块不产资源。
如果尸潮在废弃仓库上，废弃仓库也不产资源。
________________________________________
17.3 尸潮抽牌
当前玩家移动尸潮后，可以从尸潮所在地块相邻的一名玩家手中随机抽取1张资源卡。
如果该地块周围没有其他玩家的营地或堡垒，则不能抽牌。
________________________________________
18. 尸潮进度条
18.1 尸潮进度条初始值
游戏开始时，尸潮进度条为0。
________________________________________
18.2 尸潮进度增加条件
以下情况会使尸潮进度条前进1格：
情况	效果
掷出7	尸潮进度+1
探索翻出感染区	尸潮进度+1
使用“尸潮逼近”发展卡	尸潮进度+1
________________________________________
18.3 尸潮围城触发
当尸潮进度条达到6格时，立即触发尸潮围城。
尸潮围城结算完成后，尸潮进度条归零。
________________________________________
19. 尸潮围城规则
19.1 尸潮强度
尸潮强度等于：
全场堡垒总数
例如：
场上一共有5座堡垒。
本次尸潮强度就是5。
________________________________________
19.2 全体防御值
全体防御值等于：
全场所有已激活民兵的数量
只有已激活民兵提供防御值。
以下内容不提供防御值：
1.	营地；
2.	堡垒；
3.	哨塔；
4.	未激活民兵；
5.	本回合刚激活、尚未可使用的民兵。
________________________________________
19.3 防守成功
如果：
全体防御值 ≥ 尸潮强度
则防守成功。
防守成功时，比较每名玩家的已激活民兵数量。
拥有已激活民兵数量最多的玩家获得：
卡坦保卫者得分牌 ×1
每张卡坦保卫者得分牌价值1点胜利点。
________________________________________
19.4 防守成功但多人并列最高
如果防守成功，并且已激活民兵数量最高的玩家有多人并列，则：
1.	并列最高的玩家各获得1张发展卡。
2.	不发放卡坦保卫者得分牌。
________________________________________
19.5 防守失败
如果：
全体防御值 < 尸潮强度
则防守失败。
防守失败时：
1.	只比较拥有堡垒的玩家。
2.	在拥有堡垒的玩家中，已激活民兵数量最少的玩家受到损失。
3.	该玩家选择自己的1座堡垒降级为营地。
4.	如果多人并列最低，则所有并列最低的玩家都各自选择1座堡垒降级为营地。
5.	只有营地、没有堡垒的玩家不受到损失。
6.	如果被降级的堡垒旁有哨塔，该哨塔一同被摧毁。
7.	堡垒降级后，原位置放回营地。
________________________________________
19.6 尸潮围城结束
无论防守成功还是失败，尸潮围城结束后：
所有玩家的全部民兵都变为未激活状态。
________________________________________
20. 民兵详细规则
20.1 民兵驻守
民兵必须驻守在自己的营地或堡垒上。
每个营地或堡垒最多驻守2个民兵。
________________________________________
20.2 民兵状态
民兵有三种状态：
状态	含义
未激活	不能使用，不能提供防御值
准备中	本回合刚激活，暂时不能使用
已激活	可以防御、驱逐尸潮、移动
________________________________________
20.3 激活民兵
玩家可以在自己的回合支付食物激活民兵。
费用：
食物 ×1 激活1个民兵
被激活的民兵先进入准备中状态。
从该玩家下一个回合开始，准备中的民兵变为已激活状态。
________________________________________
20.4 驱逐尸潮
已激活民兵可以驱逐尸潮。
条件：
1.	民兵必须是已激活状态。
2.	民兵所在的营地或堡垒必须与尸潮所在地块相邻。
3.	本回合刚激活的民兵不能驱逐尸潮。
效果：
1.	玩家将尸潮标记移动到任意一个已经翻开的地块。
2.	玩家可以从新尸潮地块相邻的一名玩家手中随机抽1张资源卡。
3.	使用后的民兵变为未激活状态。
________________________________________
20.5 移动民兵
已激活民兵可以移动到其他自己的营地或堡垒。
移动条件：
1.	起点必须是自己的营地或堡垒。
2.	终点必须是自己的营地或堡垒。
3.	起点和终点之间必须通过自己的运输线或装甲车队相连。
4.	终点不能超过2个民兵的驻守上限。
移动效果：
1.	将民兵移动到目标营地或堡垒。
2.	移动后的民兵变为未激活状态。
________________________________________
21. 迷雾探索规则
21.1 探索条件
游戏开始时只有玩家所在的资源聚集区是明牌，其他地块都为迷雾区域，只有玩家探索的时候才会显露出来。
只有装甲车队可以探索迷雾地块。
当玩家建造装甲车队，并且该装甲车队连接到一个未翻开的迷雾地块边缘时，立即翻开该迷雾地块。
________________________________________
21.2 翻开资源地块
如果翻开的是资源地块：
1.	该地块正面朝上。
2.	探索玩家立即获得该地块对应资源1张。
资源地块包括：
1.	农场；
2.	林地；
3.	废弃工厂；
4.	废墟城区；
5.	军事营地。
________________________________________
21.3 翻开废弃仓库
如果翻开的是废弃仓库：
1.	该地块正面朝上。
2.	探索玩家立即获得任意1张资源。
________________________________________
21.4 翻开感染区
如果翻开的是感染区：
1.	该地块正面朝上。
2.	不放置数字标记。
3.	尸潮进度条前进1格。
4.	探索玩家随机弃掉1张资源卡。
5.	如果尸潮进度条达到6格，立即触发尸潮围城。
________________________________________
21.5 翻开普通地块 / 空地
如果翻开的是普通地块 / 空地：
1.	该地块正面朝上。
2.	不放置数字标记。
3.	探索玩家不获得资源。
4.	该地块之后仍然可以作为装甲车队经过的区域。
________________________________________
22. 装甲车队规则
22.1 装甲车队作用
装甲车队用于：
1.	探索迷雾地块；
2.	穿越普通地块 / 空地；
3.	连接远方区域；
4.	与运输线共同组成补给线。
________________________________________
22.2 装甲车队建造位置
装甲车队必须建在六边形地块的边线上。
装甲车队必须与自己的以下棋子之一相连：
1.	营地；
2.	堡垒；
3.	运输线；
4.	装甲车队。
________________________________________
22.3 装甲车队移动
每名玩家每回合可以移动自己1个开放的装甲车队。
开放的装甲车队指：
1.	位于路线末端；
2.	没有被自己的两个建筑夹住；
3.	没有被自己的其他路线夹在中间；
4.	移动后仍然连接自己的营地、堡垒、运输线或装甲车队。
移动装甲车队不需要支付资源。
________________________________________
23. 营地建造规则
23.1 营地必须连接
除游戏开局放置外，新建营地必须连接自己的运输线或装甲车队。
________________________________________
23.2 距离规则
新建营地必须遵守距离规则：
任意两个营地或堡垒之间，至少间隔一个空交叉点。
也就是说：
1.	不能紧贴自己的营地或堡垒。
2.	不能紧贴其他玩家的营地或堡垒。
3.	两个建筑不能建在相邻交叉点上。
________________________________________
24. 堡垒升级规则
玩家可以将自己的一个营地升级为堡垒。
升级时：
1.	支付食物 ×2 + 金属 ×3。
2.	拿掉该位置的营地。
3.	放置一个堡垒。
4.	该建筑胜利点从1点变为2点。
5.	原本驻守在该营地上的民兵继续驻守在堡垒上。
6.	原本建在该营地旁的哨塔保留。
________________________________________
25. 哨塔规则
25.1 哨塔建造
哨塔必须建在自己的营地或堡垒旁。
每个营地或堡垒旁最多只能有1座哨塔。
________________________________________
25.2 哨塔效果
每座哨塔使玩家手牌上限增加2张。
哨塔不提供防御值。
________________________________________
25.3 哨塔摧毁
如果尸潮围城失败导致某个堡垒降级为营地，并且该堡垒旁有哨塔，则哨塔一同被摧毁。
被摧毁的哨塔从地图上移除，并回到玩家供应区。
________________________________________
26. 交易规则
26.1 玩家之间交易
当前玩家可以和其他玩家自由交易资源。
交易必须满足：
1.	当前玩家必须参与交易。
2.	双方自愿。
3.	只能交易资源卡。
4.	不能交易发展卡。
5.	不能交易胜利点牌。
6.	不能交易棋子。
________________________________________
26.2 银行交易
任何玩家在自己的交易阶段都可以进行银行交易。
基础比例：
4张相同资源 → 1张任意资源
________________________________________
26.3 普通黑市交易
如果玩家拥有普通黑市，可以使用：
3张相同资源 → 1张任意资源
________________________________________
26.4 专属黑市交易
如果玩家拥有专属黑市，可以使用：
2张指定资源 → 1张任意资源
例如：
玩家拥有弹药黑市。
玩家可以使用：
2张弹药 → 1张任意资源
________________________________________
27. 商人规则
27.1 商人初始状态
游戏开始时，商人标记放在中心感染区。
此时商人不属于任何玩家，不提供胜利点，也不提供贸易能力。
________________________________________
27.2 获得商人控制权
玩家使用“商人”发展卡后，可以移动商人标记，并获得商人控制权。
________________________________________
27.3 商人移动规则
使用商人牌的玩家，可以将商人移动到自己任意营地或堡垒相邻的一块已经翻开的地块上。
商人可以移动到：
1.	农场；
2.	林地；
3.	废弃工厂；
4.	废墟城区；
5.	军事营地；
6.	废弃仓库。
商人不能移动到：
1.	未翻开的迷雾地块；
2.	感染区；
3.	普通地块 / 空地。
________________________________________
27.4 商人贸易能力
只要商人停留在某个地块上，控制商人的玩家就可以使用该地块对应资源进行2:1贸易。
例如：
商人在农场上：
控制商人的玩家可以用2食物换1任意资源。
商人在军事营地上：
控制商人的玩家可以用2弹药换1任意资源。
________________________________________
27.5 商人在废弃仓库上
如果商人在废弃仓库上，控制商人的玩家可以使用：
任意2张相同资源 → 1张任意资源
例如：
1.	2木材 → 1金属；
2.	2弹药 → 1食物；
3.	2燃料 → 1任意资源。
________________________________________
27.6 商人胜利点
控制商人的玩家获得：
1点胜利点
只要商人仍由该玩家控制，这1点就有效。
如果其他玩家使用商人牌移动商人，则：
1.	原玩家失去商人控制权。
2.	原玩家失去商人提供的1点胜利点。
3.	新玩家获得商人控制权。
4.	新玩家获得商人提供的1点胜利点。
________________________________________
27.7 商人与尸潮
如果尸潮移动到商人所在的地块：
1.	商人仍然留在该地块。
2.	商人控制权不变。
3.	商人提供的1点胜利点仍然有效。
4.	但该地块被尸潮封锁期间，商人的2:1贸易能力暂时失效。
5.	当尸潮离开该地块后，商人贸易能力恢复。
________________________________________
28. 发展卡规则
28.1 发展卡购买
玩家可以支付：
食物 ×1 + 金属 ×1 + 弹药 ×1
购买1张发展卡。
购买后，从发展卡牌堆顶抽1张，秘密加入手牌。
________________________________________
28.2 发展卡使用限制
1.	每名玩家每回合最多使用1张发展卡。
2.	本回合购买的发展卡不能在本回合使用。
3.	秘密据点卡不需要使用，可以隐藏。
4.	当玩家达到胜利条件时，可以公开秘密据点卡。
________________________________________
28.3 发展卡牌组
推荐发展卡牌组如下：
卡牌	数量	效果
民兵动员	10	免费征召1个民兵
开路队	2	免费建造2段运输线或装甲车队
空投补给	2	获得任意2张资源
征用物资	2	指定1种资源，其他玩家将该资源全部交给你
商人	3	移动商人并获得商人控制权
秘密据点	5	价值1点胜利点
尸潮逼近	3	尸潮进度+1，然后获得任意1张资源
________________________________________
28.4 民兵动员
使用后：
1.	免费征召1个民兵。
2.	该民兵必须放在自己的营地或堡垒上。
3.	该营地或堡垒不能超过2个民兵上限。
4.	该民兵为未激活状态。
________________________________________
28.5 开路队
使用后，玩家可以免费建造2段路线。
可以选择：
1.	2条运输线；
2.	2个装甲车队；
3.	1条运输线 + 1个装甲车队。
建造位置必须符合正常规则。
________________________________________
28.6 空投补给
使用后：
从资源牌堆中获得任意2张资源。
两张资源可以相同，也可以不同。
________________________________________
28.7 征用物资
使用后：
1.	玩家指定一种资源。
2.	其他所有玩家必须将手中该资源全部交给使用者。
例如：
玩家A使用征用物资，并宣布“弹药”。
玩家B、C、D必须把自己手中的所有弹药交给玩家A。
________________________________________
28.8 商人
使用后：
1.	将商人移动到自己营地或堡垒相邻的一块合法地块上。
2.	获得商人控制权。
3.	获得商人提供的1点胜利点。
4.	获得该地块对应资源的2:1贸易能力。
________________________________________
28.9 秘密据点
秘密据点价值1点胜利点。
规则：
1.	抽到后隐藏。
2.	不需要主动打出。
3.	达到胜利点要求时公开。
4.	公开后计入总胜利点。
________________________________________
28.10 尸潮逼近
使用后：
1.	尸潮进度条前进1格。
2.	使用者获得任意1张资源。
3.	如果尸潮进度条达到6格，立即触发尸潮围城。
________________________________________
29. 最长补给线
29.1 获得条件
当玩家拥有至少5段连续路线，并且是全场最长时，获得最长补给线得分牌。
最长补给线价值：
2点胜利点
________________________________________
29.2 路线计算
以下棋子都可以计入补给线：
1.	运输线；
2.	装甲车队。
运输线和装甲车队可以混合计算。
________________________________________
29.3 路线中断
如果其他玩家的营地或堡垒建在你的路线中间，你的补给线会被截断。
分叉路线只能选择其中最长的一条计算。
________________________________________
29.4 最长补给线转移
如果其他玩家的连续路线长度超过当前持有者，则夺走最长补给线得分牌。
如果只是并列，不会夺走。
________________________________________
30. 最强民兵
30.1 获得条件
当玩家拥有至少3个民兵，并且民兵总数为全场最多时，获得最强民兵得分牌。
最强民兵价值：
2点胜利点
________________________________________
30.2 民兵计算方式
最强民兵按照玩家已经征召的民兵总数计算。
无论民兵是：
1.	未激活；
2.	准备中；
3.	已激活；
都计入最强民兵数量。
________________________________________
30.3 最强民兵转移
如果其他玩家的民兵总数超过当前持有者，则夺走最强民兵得分牌。
如果只是并列，不会夺走。
________________________________________
31. 胜利点计算
游戏目标：
率先达到12点胜利点。
胜利点来源如下：
来源	分数
每个营地	1点
每个堡垒	2点
最长补给线	2点
最强民兵	2点
秘密据点	每张1点
卡坦保卫者得分牌	每张1点
商人控制权	1点
________________________________________
32. 胜利规则
当玩家在自己的回合中达到或超过12点胜利点时，游戏立即结束。
该玩家获胜。
如果玩家拥有隐藏的秘密据点卡，可以在自己的回合公开并计入胜利点。
________________________________________
33. 完整回合示例
玩家A开始回合。
第一步：准备阶段
玩家A上回合激活了1个民兵。
现在这个民兵从准备中状态变为已激活状态。
________________________________________
第二步：掷骰
玩家A掷出8。
地图上所有数字8地块产出资源。
其中一个数字8是农场。
玩家A有1个营地相邻，获得1食物。
玩家B有1个堡垒相邻，获得2食物。
________________________________________
第三步：交易
玩家A和玩家C交易。
玩家A用2食物换玩家C的1金属。
双方同意，交易完成。
________________________________________
第四步：建造
玩家A支付：
弹药 ×1 + 燃料 ×1
建造1个装甲车队。
装甲车队连接到一个迷雾地块边缘，立即翻开该迷雾地块。
翻开结果是废弃仓库。
玩家A从迷雾数字池抽取1个数字标记放到废弃仓库上，并立即获得任意1张资源。
玩家A选择获得1弹药。
________________________________________
第五步：民兵行动
玩家A有1个已激活民兵，且该民兵所在堡垒相邻尸潮所在地块。
玩家A使用该民兵驱逐尸潮。
玩家A将尸潮移动到玩家B营地旁的军事营地上。
玩家A随机从玩家B手中抽取1张资源卡。
使用后的民兵变为未激活状态。
________________________________________
第六步：发展卡
玩家A使用“商人”发展卡。
玩家A将商人移动到自己堡垒旁的废弃仓库上。
玩家A获得商人控制权，获得1点胜利点。
之后只要商人还在废弃仓库上，玩家A可以使用任意2张相同资源换1张任意资源。
________________________________________
第七步：检查胜利
玩家A当前胜利点为10点，没有达到12点。
回合结束。

34. 尸潮围城示例
尸潮进度条达到6格，触发尸潮围城。
场上堡垒数量如下：
玩家	堡垒数量
A	2
B	1
C	1
D	1
全场堡垒总数为5。
所以：
尸潮强度 = 5
________________________________________
场上已激活民兵数量如下：
玩家	已激活民兵
A	2
B	2
C	1
D	0
全体防御值为：
2 + 2 + 1 + 0 = 5
因为：
全体防御值5 ≥ 尸潮强度5
所以防守成功。
玩家A和玩家B并列最高，都是2个已激活民兵。
因此：
1.	玩家A获得1张发展卡。
2.	玩家B获得1张发展卡。
3.	没有人获得卡坦保卫者得分牌。
4.	所有玩家的民兵全部变为未激活状态。
5.	尸潮进度条归零。
________________________________________

场上堡垒数量如下：
玩家	堡垒数量
A	2

D	0

尸潮强度 = 5
________________________________________

玩家	已激活民兵
A	1
B	1
C	0
D	0
全体防御值为：
1 + 1 + 0 + 0 = 2
因为：
全体防御值2 < 尸潮强度5
所以防守失败。
拥有堡垒的玩家是A、B、C。
D没有堡垒，不参与惩罚比较。
A有1个已激活民兵。
B有1个已激活民兵。
C有0个已激活民兵。
C是拥有堡垒玩家中防御值最低的玩家。
因此：
1.	C选择自己的1座堡垒降级为营地。
2.	如果该堡垒旁有哨塔，哨塔一同摧毁。
3.	所有玩家的民兵全部变为未激活状态。
4.	尸潮进度条归零。

36. 快速规则摘要
玩家每回合按照以下流程行动：
1.	准备民兵；
2.	掷骰产资源；
3.	如果掷出7，移动尸潮并检查弃牌；
4.	交易资源；
5.	建造建筑；
6.	征召或激活民兵；
7.	使用民兵或发展卡；
8.	检查是否达到12点胜利点。
核心规则可以概括为：
掷骰获得资源，交易资源，建造营地和堡垒，用装甲车队探索迷雾，用民兵抵御尸潮，用商人强化贸易，率先达到12点胜利点即可获胜。
